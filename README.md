\# Student Management System



A web-based Student Management System developed using Django and SQLite.



\## Features



\- Add Student

\- View Students

\- Update Student

\- Delete Student

\- Django Admin Panel



\## Technologies Used



\- Python

\- Django

\- SQLite

\- HTML

\- Bootstrap



\## Installation



1\. Clone the repository



git clone https://github.com/vishnu123s/student-management-system.git



2\. Move into project folder



cd student-management-system



3\. Install dependencies



pip install django



4\. Run project



python manage.py runserver
